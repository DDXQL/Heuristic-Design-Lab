# 机制结论：固定成员对与权重校准（train21）

**本轮限定的简单组合族取得了完整训练收益。** 12个人工规定的网格候选全部通过21实例与确定性复检，5个超过H0，7个超过各自较好的固定组成成员；没有失败、加时、补跑或新增模型请求。它们不属于LLM生成/演化，也不进入旧种群。

最佳为**(H0,H1)等权**：fitness −1.983144，对H0的−2.111805提高0.128661，平均Cmax/LB降低6.09245%。对H0为16胜3负2平，对H1为16胜1负4平；相对事后逐实例挑选H0/H1的参照，平均分也高0.064324，但仍有14胜4负3平。收益不是所有实例一致改善。

主要收益例：Behnke13/14/19的Cmax从H0的316/348/670降至256/263/429。全部退化例是Behnke25的95→103、Behnke21的96→103、Behnke43的94→101；相同例是Behnke27、44。完整21行及所有12候选都保留，不能只引用胜例；另一个候选(H0,H1)权重(.25,.75)虽仅9胜12负，完整fitness仍略高于H0，说明胜负数不替代归一化均值。

**成员对与权重均重要。** (H0,H1)三个权重均胜H0，(H0,H3)等权及(.75,.25)胜H0；(H0,H2)三者均未胜H0。(H3,H6)等权及(.75,.25)胜固定H3/H6，却仍未胜H0，不能因旧冠军使用H6便预设互补。四对各三权重的252个逐实例两两比较中，物理排程全部不同；其中7次Cmax相同，证明成绩相同不能当作排程相同。这不是同状态“正确动作”标签。

最佳候选单遍h评分1,999,648次，复检同数，求解/复检各约10.45/10.44秒；本批总认证调用为每遍23,749,616次，两遍47,499,232次，主评价墙钟合计285.96秒（不能再加内部计时）。所有候选均3800步、每步两成员，但调用数随调度路径下合法动作数变化。固定h历史调用未知，历史计时与本轮资源未严格隔离，不作精确速度倍数结论。

既有B3原动态成员对/权重为−2.424245、B5原固定对/动态权重为−2.329617，均低于本次最佳；成员对、公式及选择过程都不同，不能把差距单独归因于“固定权重优于动态权重”。当前证据支持先把成员对与粗权重校准作为强基线，再检验动态性，而非先增加组合复杂度。**下一轮只建议：冻结(H0,H1)，单独检验状态相关权重能否超过固定等权基线，另行登记搜索及独立检验条件；本轮不执行。**

本结果是同一训练集上的12格选择，尚未独立验证，不能视为泛化收益或全部组合空间的结论。[全部表图](Results.md)、[最佳源码](Best_candidate.py)、[最佳完整评价](Best_candidate_result.json)、[逐实例差值](Instance_comparisons.csv)及[历史参照](Historical_comparison.csv)均可复核。
