# Fusion V4 独立协议：进度相关 WS/Borda 切换

基于 `270e068`。本轮不更改 V1/V2/V3 源码、协议、数据、账本或结果，不追认 V3 H0/H5 隔离结果，不重评该策略。只新增 V4 生命周期收集器及六个进度策略，复用冻结 V3 排程内核。

## 生命周期门禁

旧 V3 全部结果已返回，前后身份一致，但收集器只 join(0.05)，随后 terminate 得到 -15。具体退出延迟成因不能由现有记录确认；该结果继续隔离。

每实例的 `poll(15)` 结果等待完全保留，两遍求解及该实例留证共享原期限。仅在全部期望行已收齐且没有失败后，独立 `join(timeout=2.0)` 等待进程正常退出；此阶段不接收新结果、不启动求解、不延长尚未回传结果的期限。原 poll/recv 边界也保持不变，不声称新增硬中断机制。

超时/错误仍使用旧 0.05 秒 join 及 terminate/kill 清理。新正常结果必须有完整源码及加载身份、同 PID 的 before/after、终态不存活且 exitcode=0、仅正常 join 清理记录。2秒后仍存活、异常退出、未知身份或未知终态必须停止。已知超时整策略 null，不重评、不增加期限。持久化失败也清理进程。

正式评价前必须通过针对性 Mock 和回归测试，另保存真实 spawn 的合成回传后延迟0.25秒证据：旧实现被终止，新实现自然 exit0。Mock 不消费正式 FJSP 预算；验收源哈希纳入新协议。

## 预先固定科学方案

- H0/H1，固定 .5/.5；WS 与 V3 原始有限分数并列平均秩 Borda 完全复用。
- 六策略：WS→Borda 和 Borda→WS，各阈值 .25、.50、.75。
- `progress=已排工序数/总工序数`，原七维状态不变。`progress<threshold` 使用前算子；等于或超过使用后算子。每实例预期一次切换，两算子均被访问。
- train21、seed501、原 H0–H9 身份、动作合法顺序、首最大值同分规则、LB 和平均 −Cmax/LB 不变。每个实例从空排程首解和复检各一次。
- 最多126项、252遍；真实LLM/API=0，无演化、无新算子、无额外阈值，无 holdout 访问。失败不能用前缀均值。
- 固定 WS 和固定 H01 Borda 复用完整已认证历史结果及轨迹，绑定身份与哈希；零基线重评。旧 V3 Stop、checkpoint 和 H05 隔离证据也绑定保护哈希。
- 未知预留、孤立证据、身份失配、异常终态、预算越界停止，禁止自动重试。新目录不是重置旧预算的方式。

## 记录与分析

首解记录状态、全部合法动作及 H0/H1 评分矩阵、实际算子和选择，复检验证完整结果/物理排程一致。离线对同一物理状态和矩阵重算 WS/Borda，核验实际动作、同分及动作差异；不增加 H 调用或求解。验证切换前与固定前算子的提交动作共享前缀，记录首次分歧与逐实例完整排程哈希。

比较六策略与两个固定基线：完整 Fitness、逐实例 Cmax/score 差值和胜负平、两算子使用步数、实际切换次数/相邻决策对频率、边界动作改变、物理排程一致性、运行成本和生命周期证据。均值改善若出现，分解到实例贡献；局部动作差异不直接证明最终收益的因果机制。

结果仅为六个预定进度日程在已开发 train21 的描述性比较，不是新测试集泛化、动态切换必要性或 LLM 演化效果证明。全部不优于 WS 时不扩阈值追分；有改善时仅提出后续预注册等预算 A/B 建议，不执行新搜索。
