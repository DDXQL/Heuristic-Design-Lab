# TSP专用10H构建与汇报协议 V1

本协议在任何新真实请求前固定。它用于构建一个可供新版纯路由使用的TSP专用集合，不声称正式复现上游EoH-S。默认真实请求关闭，正式H构建、恒选参照和U搜索均由用户在终端分别启动。

## 依据与最小方案

已有证据入口：`reports/baseline-a-provenance-timeout-audit-20261024-v1/REPORT_ZH.md`第2节、`H_mapping.csv`、`Historical_source_identity.json`；算法实现为`code/fjsp_usage/research/sets.py`。

历史FJSP实际链路为v1积累6个有效H，v2显式导入后增加至8个，v3再导入8个、产生2个有效初始化H并完成两代各10次尝试。v3新增22尝试中20有效、1解析/约束错误、1无效评价；H父代抽样seed=7。搜索使用本项目最小互补父代/生存适配；最终集合经训练均值/稳定ID排序编号、人工审查后冻结。后续v22及当前FJSP只是显式复用这些代码和编号。不能把多次导入当作多次新生成，也不能把当前源码冒充已完全恢复的历史源码闭包。

本轮选择**独立I1候选池＋现有CPM一次互补筛选**：这是现有初始化、完整评价及CPM代码的最小组合。Tier 1不是当前主要创新点，先建立来源清楚、能验证的给定H集合；不新增H生成科研机制。

## 问题、数据与评价

二维单位方形float64欧氏完整图，城市0起止，所有城市恰好一次，闭合边计入长度，不做局部搜索。H为五参数`priority(distance_current, distance_start, mean_remaining_distance, nearest_remaining_distance, progress)`；四个距离输入除以sqrt(2)，progress为已提交决策/(n−1)。最大raw score选城市，平局取城市ID较小者。H的评价通过已有纯路由构造器，仅加载该H、以恒定U选择它；不是旧SELECT/MIX融合。

正式输入为已核验的历史train20，每例50城；文件逐个从归档按SHA恢复。它是已使用的开发训练数据，不是新测试集。NN确定性从0开始、城市ID破同分并闭合。禁止读取validation/confirmation/transfer用于本轮生成或筛选。

`s_ij = −L(h_i, x_j)/L_NN(x_j)`；`F(h_i)=sum_j s_ij/20`，越大越好。NN是参考值，不是下界、最优值或最优性gap。完整train20均成功才有Fitness，不能对子集平均。

CPM：先取最大F成员；此后每轮令`e_j=max_{h in S}s_hj`，选择使`sum_j[max(e_j,s_ij)−e_j]`最大的未选候选。增益平局按F降序、稳定任务ID升序（现有实现的预排序）；零增益仍按该顺序保留，不自动减少K。最后重新按F/ID排序编号；生成顺序、CPM选择顺序、最终编号分别保存。

## 预算与停止

- 推荐H预算：**40逻辑槽／最多40次HTTP尝试／每槽1次**。10是最终保留数，不是请求数。全部槽位结束后一次选择，不在凑到10条时提前挑选。
- 传输失败、完整响应但解析失败、非法程序、重复、无效评价均消耗所属槽位。重复复用本运行已有评价，不另发请求或重复求解。失败不补发，余量不自动转入U阶段。
- 最大800程序×实例行，1600遍首解/复检；重复和失败可减少实际量。API和候选评价串行（各1），复用已验证的单写者任务执行器与账本。每行T30完整首解/复检，另有2秒子进程退出宽限。
- 12小时持久运行窗口，恢复不重置；开新候选前保留该候选网络及完整评价的保守余量，不足则expired。按T30与单请求300秒计算40槽的保守预留约10小时，实际不承诺该时长；CPU/落盘开销另计。
- 认证/余额/型号/参数等硬错误立即持久停止；连续3个逻辑传输失败也停止。单个临时错误记失败后进入下一新槽位，无自动重试。真实服务可用性尚未通过本轮在线验证。
- 未知发送、未提交任务/评价、锁、Stop、源码变化或哈希不一致阻止自动恢复。只对安全paused使用原预算resume，不清锁、不删记录、不复发未知任务。
- 全部槽结束后有效去重H不足10条：执行队列可为completed，但`H_build_outcome.json`为`insufficient_valid_unique_H`、CLI退出码2，不产生H_frozen、不缩K、不补人工、不新增预算。不得把“队列完成”写成“10H构建成功”。

## 开跑前固定的分析与汇报口径

1. H：完整训练质量矩阵、最终冻结清单、来源/编号/CPM顺序。互补性报告逐实例包络相对最佳单H的增益，以及移除某H的包络损失；这些是诊断，不是可部署路由质量或其上界。相同分数/行为可能保留，真实结果也可能没有互补增益。
2. U：最佳完整训练Fitness对累计请求槽位（含初始化、失败和重复）的阶梯曲线。仅从第一条有效已提交结果开始，不用虚构零点补线。每完整代报告种群中不同“全部实例H选择序列向量”的数量，保留真实平台期。
3. 基线：只接受完整、同问题/有序实例内容、NN参考、H代码及顺序、求解seed、T30、窗口/启用字段及相关求解源码身份一致的恒选全集。按完整train的Fitness/ID选择最佳恒选H，按同样规则展示当前已提交U冠军。没有基线/不兼容/未完成时保留占位，不能混用旧5H、FJSP或旧SELECT/MIX结果。
4. `ΔF=F_U−F_B`；相对变化`100*ΔF/abs(F_B)`，对应平均归一化长度的相对降低。另列逐实例`100*(L_B−L_U)/L_B`，不混称两者。长度比较以绝对容差1e−12统计胜负平。所有选择都是训练描述；没有训练外验证就不声称泛化。
5. H固定预算节点10/20/30/40保留已提交候选池快照。H无演化，代数恒0，不能生成假代际种群。U保留每代原生种群/父代计划和代数节点5/10/15/20；另保留累计请求阈值50/100/150/200/220后的首个批次边界快照，明确target和observed（可能有小幅批次越界，不伪称恰好在阈值停止）。
6. 开始/结束、执行段实际耗时、含暂停的总墙钟、暂停/恢复记录单列。进行中汇总显示截至时间、实际预留请求及已完成代数；已提交结果来自任务cursor或已结算批次，未知在途不作为候选成绩。检查点“running”不保证进程仍存活。

普通结束和安全暂停后自动尝试离线汇总；失败只写报告错误，保留原始结果，独立汇总可重试。不在汇总中发API、求解、重新选择或冻结。输出中文报告、CSV、PNG与SVG（文本保留可编辑）；Mock图和报告显著标为工程验证。缺少基线与训练外结果不阻断其他图表。

## 尚未验证的假设

40次能否产生至少10个合法去重H、是否具有实际行为互补性、LLM描述是否准确反映程序、集合是否有利于路由学习，以及20个旧训练实例能否代表未来任务，均未得到真实实验验证。自动准入不替代人类语义审查。后续的H演化、扩大候选池、行为去重、H重编号和新测试集只作为独立研究建议，不在看到结果后自动加入本轮。
