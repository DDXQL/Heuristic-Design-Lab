# Fusion V3：等权并列平均秩 Borda，2026-10-24

独立新版本，不改V1/V2源码、协议、原始记录或账本。本轮由执行Agent按用户连续授权启动。
最多三个固定策略，63项实例评价/126遍首解复检；不调用LLM、收费服务或U演化，不访问validation11/test28。

## 科学变量

唯一新增机制BORDA：对每个成员的**原始有限H动作评分**求并列平均秩。
动作a的B点数为 `#严格更小 + (#相等 - 1)/2`，越大越优。
两成员等权；计算时保留 `2B0 + 2B1` 的整数值，最终argmax等价于均值百分位秩
`(B0+B1)/(2*(N-1))`，N=1时定义0。常量列为共同偏移，对动作排序无贡献。

Rank Sum（小秩为优取最小）和Borda（大点数为优取最大）是同一机制的仿射表示，不拆成两个算子。
每列并列使用平均秩，不能提前按动作编号拆并列；最终精确并列使用旧合法动作枚举首项。
不使用epsilon、softmax、分段参数、随机破同分或可优化秩权重。
接口为可信 `U(原七状态)->('BORDA',vector)`，vector恰有两个等值正支持项；固定为0.5/0.5。
权重/数值合法性沿用V1/MIX解码；上步主导成员为两者小编号，与历史等权保持一致。
旧SELECT/WS/MAX/MIN在新版本内显式委托旧数学实现；原执行器无注入接口，故新模块保存独立调度循环，回归检查状态/动作/排程逐项一致。
这不是LLM闭合AST扩展，也不构成已经支持LLM生成BORDA的声明。

## 选择依据与冻结策略

阶段A只读取V2成功首解记录（含无效策略成功前缀），按完整物理状态/实例/历史成员去重。
全部31200个状态出现、30245个去重状态重组Borda/WS/MAX/MIN；不重新求解或调用H。
精确WS可表达性检查：每对seed501确定性reservoir64，样本不按效果筛选。
Fraction约束考虑“先出现动作必须严格小于目标、后出现允许相等”；端点保留原始SELECT语义。
结论是保存的归一化浮点值上的实数线性可表达性，不能无条件等同所有IEEE运算结果。

三对去重状态中Borda不同于WS的计数为6643/11346、3689/9571、3552/9328；
64状态样本的实数WS不可表达数为27、16、8。故选择Borda，而非再改WS权重或新增另一融合机制。

正式策略预先固定：(H0,H1)-BORDA、(H0,H5)-BORDA、(H5,H9)-BORDA。
保持冻结H、train21原顺序、seed501、未取整LB和mean(-Cmax/LB)、同分规则。
H5已知超时风险如实保留，不为了完成率临时替换成员对或过滤实例。

## 评价与异常边界

每策略每实例从空排程首解/复检各一次；15秒父管道等待期限不增加，覆盖原有求解及留证回传准备，
不是可在recv任意阶段强制打断的硬实时上限。首解保存全状态和全部动作评分，复检不记录轨迹。
结果对象、物理排程、H调用次数一致才有效；任一实例失败则整策略Fitness=null，不算前缀均值。
不重评超时或未知中断任务。每个策略先持久化21项/42遍预留，最多3策略；已完成结果验证SHA，未知预留停止。

复用V2经测试的生命周期收集/严格分类。正式子进程前后对比加载字节码和绑定源码；文件边界覆盖新旧依赖、数据及旧结果。
正常结果须有前后身份和exit0；明确超时只有起始身份、整套文件不变、父等待触发、确认terminate/kill退出码且不再存活时才可记无效继续。
其他身份、进程和预算问题一律停止；不得补造结束身份或修改旧记录。
网络和非训练FJSP读取安装拒绝审计钩子；训练原件/V2副本/新副本的精确train21路径仅供身份核对。
