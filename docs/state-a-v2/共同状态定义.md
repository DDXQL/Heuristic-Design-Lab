# 方案A共同状态：本轮冻结定义

冻结日期：2026-11-11。公共接口版本：`common-state-a-v2`；U接口：`pure-routing-state-a-v2`。本轮采用下表10项数值及明确列出的辅助信息，不增加问题专用字段。方案B仅保留为历史讨论。

来源：[研究决定及评分要求](https://app.notion.com/p/41204e0510d781f3a328c11ed393a1b1)、[计算口径](https://app.notion.com/p/41404e0510d7804fb660c75b198e36d0)。本表是研究决定的工程冻结，不表示10项的信息价值已经得到实验验证。文献支持状态驱动选规则的方向，没有直接验证这10项。

## 计算约定

每步先枚举合法动作、计算状态，U返回一个H编号，仅被选H给合法动作评分，提交一个动作后更新历史。状态提取不调用H，不改变部分解，不试算续解。终态不调用U。

- FJSP：追加式调度；工序只能接在job和机器已承诺时刻之后。总决策数D为总工序数；B为所有工序各自最大可选加工时间之和；Pmax为全实例最大加工时间。第3—6项除以B，第7—10项除以Pmax。
- TSP：有限、对称、非负距离矩阵，至少3个城市，最大距离dmax必须大于0；固定城市0为起点。D=n−1；强制闭环不调用U、不进入动作历史，但计入最终路线长度。全部距离在求解前公开。
- OBP：等容量箱、允许保留所有旧箱；开始公开总物品数N，未来物品大小和顺序不公开。只有无旧箱能放当前物品时才允许新开箱，等容量空箱供应充足，新开箱是一个动作。物品大小须在(0,C]。这是本轮采用的任务范围。
- 所有标准差均为总体标准差。归一化尺度在实例内固定，不按当前样本重新缩放。无穷、NaN、非正尺度、超范围输入属于错误，不能伪装成缺失；不截断异常值。

设t为已提交决策数，A为合法动作数，q为未访问城市数，J为job数，M为机器数，b为已开箱数，W=10。表中开销只计状态计算；FJSP的工时后缀及尺度一次预计算，TSP复用已有距离矩阵。

FJSP增量不超过Pmax：当前job就绪时刻与机器就绪时刻均不超过当前部分makespan，因此下一工序使部分makespan增加至多该工序加工时间。统计量0不代表没有后续影响。

## 辅助信息及读取边界

U可以读取上述10项，以及 `previous_h_token`（上次真实提交的H类别，首步None）、`has_history`、`history_count`、`recent_history_count` 和逐字段 `availability`。H编号不代表质量排名。辅助信息不计入10项数值。

执行器另带 `problem_id`、`schema_id`、`spec_sha256`、`window`、`missing_reason` 元数据，用于核验与记录；U读取检查不允许访问这些元数据、H分数或执行器对象。字段名与允许读取集合对三个问题完全相同。

仅在没有统计对象时返回None和availability=false：首步第9、10项及previous_h_token；OBP尚未开箱第5、6项。其余非终态必有值。恒定、重复、单样本标准差0均availability=true。窗口固定10；变更窗口需新接口身份。

U仍使用 `def use_heuristics(state):`，返回内置int类型H编号；禁止MIX、外部访问、循环、调用H、修改状态。静态检查报告引用字段，运行读取记录区分值读取与可用性读取；两者均不宣称字段带来收益。

## 与最终评分的接口

状态里的动作增量只描述部分目标变化，不调用评价器、不读取LB、LKH或未来物品。最终评价统一为 `J=mean((cost-reference)/reference)`，越小越好：FJSP沿用LB_v5；TSP要求接入页传入已冻结LKH参考；OBP要求后续评价页提供核对后的下界。不得用NN或体积下界静默代替。

新构造入口给出原始最终成本、参考值及相对差距。旧搜索器按负Fitness最大化，本轮不改其历史行为；接入页必须显式采用min选优，并绑定状态、U接口、参考值与评价器身份后才能启动新搜索。没有参考值时新入口提前报错，不隐式生成参考路线。

## 相对现有代码的改动

- 新建方案A状态模块及三个问题适配器；旧 `constructive-common-v1` 的13项、旧提示与指纹保持原身份。
- 对应保留旧构造进度、动作增量均值／标准差、近期增量均值／标准差；动作宽度比例改为合法动作整数；恢复需求与资源的均值／标准差。FJSP和TSP的增量尺度按本表变更。
- 新接口不暴露累计部分目标比例、当前最小／最大增量、前两名差、上步增量、连续使用比例、切换比例、usage_fraction。上一H、历史计数及掩码按辅助规则提供。
- FJSP、TSP新增显式方案A构造入口，复用原动作及并列处理；历史只在真实提交后更新，只有所选H被调用。
- OBP实现当前物品可见的状态提取与单步纯选择会话；不接入数据集、H生成、完整求解入口或最终评价器。
- 本轮不开发方案B，也不设置A/B对照。接入与离线证据见本目录交付说明。
