## 2．前缀预览与单独获准后的提交

```bash
"$HDL_P" -s -B "$HDL_TSP" prefix-preview
```

只读检查交接和已有计划，返回准确命令、计划存在情况及限制；不prepare、activate或submit。计划已存在只检查，不覆盖或重建。已激活计划拒绝重复首前缀，须先检查原提交回执。

仅在之后明确批准首次前缀、计划创建／激活及新的全设备排他期限后，执行：

