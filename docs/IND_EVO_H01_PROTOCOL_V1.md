# IND与EVO：固定H0/H1、共同P0、20新增候选×3搜索重复

当前人类用户已授权实现、真实生成、完整train21评价、分析和本地提交；不推送，无人民币门禁。不是CROSS成绩反馈延续，不续跑A4或扩充简单规则。

## 科学变量与共同信息

固定十个冻结H的编号，仅H0/H1可正权重。沿用历史B2 H01封闭数值接口：七状态输入，输出`(1,(alpha,1-alpha,0,0,0,0,0,0,0,0))`，alpha有限且在[0,1]；端点用单H原始动作评分，双正项各H对全部当前合法动作独立min–max后归一化加权，同分按job/machine。允许静态或动态，禁止SELECT及其他成员。本批不改变输入、H或评分语义。

两组共同TASK、H_CONTEXT、H0/H1实际代码／说明、输出约束与签名；不提供网格排名、历史冠军或简单规则排名。EVO提示词直接调用原`h01_weight_search.build_prompt`，没有成绩字段。IND只将原独立初始化操作适配为H01权重接口，删去与已提供H代码矛盾的“仅知道成员数”一句；不加入设计策略。IND每次同一模板、一条新user上下文，不包含P0代码／父代／历史。双方共同初始档案和best-so-far是五个P0，EVO才通过父代流程读取它们，故比较的是完整信息利用与演化流程，不是纯交叉措辞消融。

## P0与源证据

历史B2 `MANUAL/init/alpha_{000,025,050,075,100}`；不得替换自由10H P0。逐项核对原代码key、实际alpha方向、H、train21/LB、完整21评分及原始结果SHA。端点原协议以单正项MIX/raw-H严格语义等价复用原生双解；三个非端点为完整物理排程复检。保留旧证据等级与T15包装差别，不伪造现代终态回执。可与已完成现代静态记录作离线一致性参照，但不补跑父代。

这五个已认证历史质量结果双方同用；历史P0投入单列为5策略／105项／210遍的逻辑完整评价量，本轮P0新增求解=0，不称从零仅20查询。三种端点／等权已另有现代T30一致性记录，但不会将历史成本当作同期墙钟。P0及本批成绩以外的网格不进入搜索。

## EVO原机制

N=5，两代，每代按序前5 CROSS、后5 MUTATE。父代在一代内冻结；沿用`research.evolution.select_parents`：按完整Fitness/ID排名，权重1/(N+rank)，不放回抽CROSS5（即全部5，顺序随机）或MUTATE1。每代10候选完成后，对原父代和有效新颖子代用`ranked`保留前5，Fitness同分按ID；子代ID保持原`B/g0000/...`格式。源AST去重含P0和本搜索已准入候选；重复消耗槽位，不补员，不插入种群，语义不同但排程相同不据此去重。

独立安全适配器调用上述原函数与原提示词，保留原机制；唯一必要差别是未知请求／评价reservation严格Stop，不沿用旧Search将中断评价直接转无效的宽松恢复。源文件与加载函数身份均冻结。

## 规模、随机性与顺序

搜索seed固定2026102511/12/13，求解seed501，顺序seed2026102510。模型不发送seed，不将同重复编号或候选槽位视为严格随机配对。IND seed用于重复标识与固定调度，输出随机性来自独立API上下文；EVO seed另用于父代抽样。

每重复IND20、EVO20，共120逻辑候选；六个独立请求账本各最多30 API尝试、单候选2次，全批最多180次。不补足有效数。调用以2候选小批次交错：每个相对槽位段随机排列三个重复，再随机先IND或EVO；各EVO相对槽位保持0…19，代际依赖不变。完整Tasks.json在任何生成之前冻结，父代按冻结算法结合该重复既有群体在线确定。

每个首次完整响应先落盘，再解析；解析失败或低质量不得重生。只对可靠临时传输失败按原AttemptJournal重试；HTTP524等不在原白名单中则不擅自追加重试。未知投递Stop；账户、永久错误或连续3逻辑传输失败Stop。单搜索30尝试用完时该搜索partial，后续槽位未启动，不伪称20完成；其他独立搜索可继续。

缓存仅精确AST＋相同科学上下文的P0和本campaign已认证结果；共享跨组／跨重复缓存，查询仍占逻辑候选。两组均记录本搜索重复和跨搜索复用。对重复已知质量可单列，但EVO不因此重新纳入孩子。失效结果不赋人为Fitness，不作成功前缀均值。

当前共同模型取已完成真实接口的精确配置`gpt-6.1-sol`，非流式openai-chat-v1，max_completion_tokens8192、n1，temperature／reasoning_effort／seed不显式发送。客户端约束完全一致，供应商默认采样或内部路由未知。费用只记录可得Token、原始扣点和不确定性；不设CNY换算、预留、其他账户占用门禁，不打印凭据／自动充值。

全部新评价同一T30认证执行器：完整train21、未取整LB、平均−Cmax/LB；每实例首解复检共享30秒完整接收期限，末行前结束身份、全结果后2秒正常退出宽限；未知源码、终态、复检或账本异常Stop。代码输出／数值错误仅在身份和正常退出完整认证时按无效候选继续；已确认终止的普通超时null。最高物理2520程序—实例／5040遍（120×21×2），实际扣除缓存，无额外诊断求解。

首次正式run持久化6小时启动窗口，不重置。每新任务预留1294秒（2×300秒传输＋2秒重试间隔＋21×30秒结果等待＋2秒退出＋60秒工程余量）；剩余不足不再启动。已启动按冻结规则结束。任一候选区间wall/monotonic差>2秒保存隔离并Stop，不自动重跑。临时caffeinate -i仅绑定本进程，不改全局电源，不承诺合盖计算。

脚本独立会话、文件日志、持久账本、结束摘要与汇总；无需模型逐候选监控。留存PID、锁；未知reservation不自动清理或重放。真实余额不足／API不可用保存partial。所有旧账本、报告、协议、H和其他工作树保持原样。
